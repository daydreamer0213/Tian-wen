# 修复带引号字段的记录解析

`records.py` 的 `parse_record(line)` 目前用简单的 `|` 切分，因此会错误拆开双引号内部的分隔符。
请只修改 `records.py`，并保持公开函数签名不变：

- `|` 是字段分隔符；
- 双引号可以包住包含 `|` 的字段；
- 引号内的两个连续双引号表示一个字面双引号；
- 每个解码后字段需要去掉首尾空白；
- 未闭合的引号必须抛出 `ValueError`；
- 普通无引号输入保持兼容；
- 只使用 Python 标准库。

可以按需运行已登记的 `public` 检查。不能运行任意 Shell，也不能读取最终验证器或参考答案。
