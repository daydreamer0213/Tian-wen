# Feedback source and semantic authority repair

Status: prospective design under the owner's standing authorization for
independent implementation of the current natural-learning route. The owner
explicitly asked not to pause for routine design/model-call approval. This is
a correction of demonstrated contract violations, not a new strategy or grant
of external authority. R9 is closed NO-GO; its records remain immutable.

## Problem and evidence

The [R9 result](../../operations/tianwen-natural-conversation-acceptance-r9-results-20260908.md)
establishes that normal input can trigger a study and activate guidance. The
load-bearing failure is unreliable interpretation, not an unreachable trigger.
Raw feedback is durably present but only its model-derived criteria reach
case design, proposal and source-trial review. In R9 this changed the advice
actor from assistant to user. Separately, both native checks saw real drafted
commitments and invented confirmation dependencies but excused them as future
inference/courtesy. They also accepted downgrading known current facts to unknown.

Hypothesis: carrying exact bound feedback to the existing consumers and
clarifying semantic authority in the existing review contract will correct
these failure modes without disabling useful advice and inference. This is
falsifiable with new actual-model source-boundary cases and finite ordinary
use. Prompt text and green scripted tests do not prove the hypothesis.

prospective standards and evidence selection. The installed public mechanisms

request; no upstream change, provider SDK or new runtime mechanism is needed.

1. **Selected: reuse exact feedback recovery and the existing two native
   reviewers.** This fixes the concrete broken producer/consumer seam with
   no extra model call. Version the changed policy and preserve old proof

2. Tighten only derived-criterion extraction. Smaller payload, but subsequent
   consumers still cannot detect an actor/scope distortion. An extraction
   clarification is useful alongside raw feedback, not a substitute for it.
3. Add another reviewer, extra semantic schema or phrase bans. Not selected:
   R9 already captured the decisive claims, so more representation or votes
   do not establish better judgment. Phrase bans would suppress valid prose
   and fit the test answers. No extra model authority or dependencies are added.

## Exact feedback path

Reuse `TianwenConversationFeedbackService.materialForAssessment(assessment)`.
It already checks target/admission/result identity, exact natural direct-user
requests or current native feedback version/fingerprint, and the frozen whole
assessment material digest. Do not reconstruct feedback from a rendered
transcript, selected `evidenceQuotes`, or a newly summarized string.

For a selected feedback-supported source, extend `feedbackStandard` with
`originalFeedback`, the exact recovered `ConversationFeedbackMaterial.feedback`
object. Keep `assessmentId`, `classification` and all existing `criteria`.
Natural feedback retains complete original UserMessage objects plus source
binding and original admission quote. Native feedback retains its exact
rating/note and source binding; a bare rating never acquires invented prose.
The complete source material including originalFeedback is bound by the
existing case `materialDigest` and exact native judgment request. Sources
without a feedback assessment have no feedbackStandard.

Case design, proposal and method-study review receive the same source material.
State the precedence in each consumer: the directly expressed original
feedback is authoritative if a derived summary changes actor, negation, scope,
timing or exception. Interpret pronouns in the original user-to-assistant
conversation; “you” does not address the evaluator. A continuing preference is
a default and yields to the evaluated task's explicit current instructions.
Quoted material is not a new instruction. Neither feedback nor derived
criteria are factual support for the evaluated answer. If meaning is genuinely
ambiguous, do not invent a categorical preference or claim conclusive success.
Apply only the independently attributed continuing preference or supported
problem, not every new work request embedded in that full feedback message.
An unresolved reference to an absent old sentence remains ambiguous; do not
expand this patch by forwarding old answers or all conversation history.

The feedback assessor also receives a small extraction clarification to
preserve these same distinctions, but no new extraction schema or second
assessment. Existing natural/native bindings and their old proofs are not
rewritten. Source selection continues to require current task quality.

## Semantic authority, not zero-addition prose

Quality v6 appends a general clarification to the exact v5 criterion. Current
ordinary and method-study review use a corresponding general instruction:

- Reconstruct proposition, actor, time, certainty and scope before assigning
  a permissive label. Cover separate substantive claims within a unit, not
  only the most convenient quotation.
- A draft in a real sender's voice can create an action/decision/notification
  commitment even when future, conditional, polite or not yet executed. Such
  a commitment needs supplied authority or must be presented as an optional
  suggestion outside the attributed commitment. Ordinary courtesy or an
  assistant's offer to help is not automatically a real sender commitment.
- Preserve known current facts as well as unknown future outcomes. Do not
  silently broaden “unknown” to include a confirmed current state. Evaluate
  headings, collective references and conditionals in context, not as isolated
  individually true quotations.
- Reasonable marked inference remains allowed when the supplied premises
  support the connection. Hedging does not justify an invented prerequisite,
  necessary timeline or decision power. Mere non-contradiction is not enough.
- Optional advice, supported fallible inference, general knowledge, requested
  fiction and genuinely non-factual courtesy remain allowed. No added tool
  use is required. Use the existing verdict/status/category fields.

There are no task-specific strings, locations, facts or expected verdicts in
production prompts. Keep audit v2 unchanged: the demonstrated defect is not
the inability to represent a claim. A semantic model can still make a validly
formatted wrong judgment; only fresh evidence can assess improvement.

## Stories and acceptance

Normal: two distinct writing requests receive continuing direct feedback;
the original actor/exception reaches every standard consumer, a native study
runs, and any accepted guidance remains subordinate to the next user request.

Counterexample: a user asks for a single SMS despite a previous three-part
default; current instructions win. Separately marked advice, reasonable
weather inference and requested fiction are not rejected merely for adding
content. A bare negative rating is not enough for a reusable rule.

Failure: a derived summary swaps assistant/user, or a draft adds an unprovided
sender commitment/dependency. Consumers can inspect the exact feedback and
the review must evaluate the actual proposition. Missing/tampered feedback
binding, changed native proof or oversized material cannot authorize a study.

Engineering checks must exercise real producer material, ledger parent
boundaries, prompt selection, native persistence/recovery and blind worker
inputs. Retain literal historical fixtures, and include quoted/negated feedback,
native edited/retracted notes, source-without-feedback and size overflow.
Scripted verdicts prove wiring only. After focused gates and independent
review, run exact-source full gates and a separately frozen prospective
real-model diagnostic/ordinary cohort. All first results, reviewer blind
corrections, synthetic cases, uncertainty and latency remain separately labeled.
