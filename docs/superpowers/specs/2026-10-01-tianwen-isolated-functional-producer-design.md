# 正式冻结功能结果：隔离Python JSON CLI生产者

实际存储任务的33冻结检查与单独摘要失败证明窄功能执行可发现编译无法证明的问题，但它未进入正式账本/研究，不能补旧task资格。现external/study接口注释禁止任何生成代码执行，必须明确变更为仅显式宿主配置的已验证隔离边界；旧只读/编译默认与历史保持，不给模型新增执行工具或自动开启。

实现两个具体脚本模块：受限Docker Python runner，普通任务/研究共用冻结准备的JSON CLI检查生产者。不是新增空接口、更多模型评审或复跑旧题。宿主在作答前提供原请求、唯一target、显式参考、独立输入/期望输出/退出码及原必需条件。全量深拷贝并绑定检查器/runner/固定镜像/策略/原文件/原请求/案例；案例不由待评答案反推。研究消费原保存files/criteria/完整body，不读取今天的项目内容或假造普通Task。

runner固定digest镜像/CLI，先核对镜像及实际create后inspect再start；仅source argv和input stdin，无挂载/凭据/网络/宿主执行，非root、只读root、cap-drop ALL/no-new-privileges、CPU0.5/128MiB无extra swap/32pids/16MiB tmpfs/有限日志。每例≤20s、输入和输出各≤32KiB、源码≤20KiB，最多64例。UTF-8严格校验、退出状态及CLI运输一致；始终核对唯一名称/label/image后清自有容器，丢创建响应按名称追踪，未知/失败清理停止，不假定已删除。镜像不pull，不新安装，不启动Docker或下载环境作为prepare副作用。显式D工作根，小回执，不存全Profile/重复源码。

JSON期望比较不依赖JS浮点舍入或对象键顺序：严格解析有界JSON，拒重复键，十进制数按精确值比较；未完整运行/超时/OOM/超输出/运输或隔离失败/取消/输入绑定不符=unverifiable。完整返回且输出/退出不符=原功能rejected，仅明确原必需条件opt-in才附失败摘要；越权输出/参考变化不能冒充原要求失败。只读/编译接口默认不变，方法采用/发布仍受原治理。
