## 最小方案与取舍

扩大上限或拆批评价都会改变调用成本、完整答案判断及证明合同，当前没有依据，不选。沿用现有限额：整体 JSON 512 KiB、答案 32768 UTF-8 字节、128 个答案单元。空答案、非法形状及身份/摘要不符仍为 `invalid-judgment`。

在现有投影处抛专用 `ConversationClaimReviewMaterialError`：message 仍为已有 `material-too-large`，字段仅含 limit（material-bytes / answer-bytes / answer-units）、actual、maximum。不保存内容、路径、引文或模型输出。在普通 observer 的失败记录中使用现有 unavailableReason；解释携带这些数字，并明确未尝试自动结果评价。不扩展账本 schema 或记录平台。

取消优先，不能把撤回伪装成超限。检查提前停止，不截断答案、不省略文件、不把拒评写成 `not-met`，不授权来源、accepted 或激活。整体材料 byte 限额仍在解析前检查；每条研究答案及普通组合答案仍有原 byte 限额，计数仍在完整投影后检查。
