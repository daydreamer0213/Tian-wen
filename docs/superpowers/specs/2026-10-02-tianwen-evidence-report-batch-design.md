# 真实证据报告批次：前瞻设计

所有者2026-10-02批准自行设计环境并执行：任务结果未知、依据先于答案固定。完整自动学习仍是目标，原发布门槛、十工作日窗口、main/Daily NO-GO与正式激活隔离不变。

## 实际用途与现有能力

当前项目报告必须分别表达普通任务、研究决定、方法采用及未来效果。现有 `summarize-functional-checks.py` 仅索引功能检查；learning_status已有研究状态与独立结果统计，不重新实现其资格/采用规则。需要的是供当前报告使用的离线、有限事实投影与回归对账程序，不建立第二个Runtime、验证平台或新的资格规则。

批次包含三个不同实际交付：`scripts/summarize-task-evidence.py`（原任务完成/模型复核/当前功能检查分别统计）、`scripts/summarize-study-evidence.py`（自然/受控研究、accepted与激活记录分别统计）、`scripts/reconcile-regression-evidence.py`（保留首轮失败，仅同版本同案例集合的完整补跑可替换当前计数）。三项均为Python标准库JSON stdin/stdout程序，目标内read/write/edit，禁止模型执行程序。宿主使用现有固定镜像的隔离功能生产者核验。

三个程序有真实报告消费用途，不是预定的失败样本。实际任务数据取正式持续档当前10任务；研究数据取本项目已保存的真实受控研究执行记录并明确controlled；回归数据取2026-10-02组合回归及环境纠正记录。读取这些记录作为新程序输入，不重评历史答案/研究、不重新运行历史模型任务或测试。

## 共同条件与身份

原必需条件统一为：**严格遵守原合同的输入有效性、证据归属与统计规则；不同证据状态不得混算或提升为整体完成；有效输入返回规定JSON/退出码0，无效输入返回规定错误/退出码2，stderr为空。**

条件只覆盖各自原合同，不证明开放文本语义。三个具体合同、请求、案例及输入先冻结；没有结果后增加标准。普通及研究检查共用同一个绝对workRoot、CLI、镜像、政策、模型配置、质量合同与当前作用域。运行目录参与executorDigest，分任务换目录会阻断原有兼容身份；使用同一环境是配置选择，不修改产品匹配规则。

## 未知结果、研究与后续

每项普通任务一次真实原生尝试、零重试，模型原稿不由控制器补写修复。源码上限统一为既有生产者的20,480字节；首版20,000与编辑后的总长检查不一致，在任何模型调用前修正并保留首版冻结包/零模型预检。任务完成后保存原输出、模型原复核、正式功能结果、实际消费结果和来源身份；环境/驱动失败单独归属。只有现有产品规则识别的合法两条来源和成功对照才运行研究；不预分配“失败题”“成功题”，不代写用户反馈。真实持续偏好是另一合法来源，不需要将成功改判为失败。

独立研究任务在方法生成前冻结，使用不同输入事实和原依据，复用closed五角色生产者。只有实际来源选择发生后，按保存原请求/完整材料精确装配来源角色，不能从答案反推检查或用当前文件代替原输入。装配及全部五检查必须先于设计模型调用；缺绑定停止，无fallback。三个普通任务若均成功，只记录本批未产生新功能失败；若原选择器没有合法组合，记录本批未触发研究，不能据此推断无偏好或无学习需求，也不能称自动学习完成。

两项预留任务为：控制运行事实对账（新合同区分真实模型请求、脚本请求、执行检查次数与冷恢复次数）和历史采用/后续使用证据摘要（只报告显式使用版本与结果证据，不推断收益）。具体完整包必须在原生普通批次启动前冻结；不能先列空接口，再让方法决定题目或答案。前瞻未来验证使用后续新增记录，不借历史成功证明新方法效果。

## 停止与资源

控制失败、准入/材料不可用、绑定漂移、取消、结果无法判定或原模型复核不完整时保留原状态，不重跑本题求成功。程序拒绝只有精确违反原必需条件才可成为来源；原检查失效消费者保持。每任务最多14次声明文件工具、9次根模型请求、12分钟；超限停止，不增加预算续跑。使用现有DEV Profile和依赖，生成物在D:/DevData，仅留必要原生压缩记录、合同、原候选、结果/清理回执。启动前D剩余≥15GiB，优先20；若不满足先安全清理自有可复现产物。既往自动审批拒绝的删除不重试或绕过。
