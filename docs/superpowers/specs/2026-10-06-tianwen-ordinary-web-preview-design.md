# 当前普通 Web 预览：一次有限使用旅程

继承用户持续自主推进、允许主动模拟条件、D盘至少15GiB/偏好20GiB的授权。既有日常研究预览0.1.24/preview.25已经交付；本次检查当前开发代码通过普通Web输入能否正常使用，不重新验收旧产品，也不解除main/Daily完整自动学习的隔离。

现有受控DEV学习闭环已完成，当前语义八例7匹配/1分歧已收口。本次不要求每次模型判断正确、不强求新研究/方法，不重跑旧题或重开消费者覆盖。检查对象是当前Runtime普通apply（默认quarantine）与原SDK/Web的真实整合；模拟偏好不称用户真实评价，回答必须是实际模型首次输出。

比较三种路径：复制/升级现有桌面会改动日常环境并占空间；只调用底层评审不能证明普通入口；薄独立Profile共用现有SDK和Web、加载当前Runtime普通apply，能以小代价查普通输入到记录和关闭的整合。选择第三种。没有新UI、Agent引擎、评审服务或依赖安装。

新profile使用原base/web bundle、已安装原agent-loop公共入口、原native tools observer和JSONL持久化。当前Runtime通过公开runtime导出按普通apply挂载，显式新state/evolution根位于profile内，不调用applyDevelopment、不提供DEV裁决策略、不链接旧Session或账本。只复用同一个已有DSH_HOME的提供者设置，profile独立，不复制凭据。禁止模型浏览其他配置/账本；不挂新文件/命令工具。

用户旅程通过原Web实际输入四条预冻结消息：U0只启用本独立配置的新对话分析；U1基于明确当前事实为第一次使用者写一段天问使用介绍；U2模拟持续表达偏好并请求改写；U3关闭本配置分析、保留记录并查询当前状态。正文属于实际模型交付，控制者不补写。U2只证明模拟反馈在当前产品的处理，不证明真实用户满意或原答有客观错误。状态不能以聊天中的自述替代原工具/持久记录。

实际DeepSeek配置沿当前已核实的deepseek-official/deepseek-v4-flash/high/maxTokens65536/retry0。40请求/20分钟/D>=15GiB仅为运行资源边界，不是产品发布门槛。操作器负责计数、保护文件、保存原生首记录与正常排空；UI输入由root执行。预检实际挂载原Runtime、确认默认激活暂停、原factory创建/关闭健康及0模型。serve不自动发消息或开启同意。root在U3结束后发本操作器的停止请求；沿原consent/observer/feedback/Loop关闭，flush并退出原CLI。冷读取在关闭状态0模型，已有Task/feedback/study/attempt及账本保持，不恢复历史Agent。

独立审计分别记录实际入口、模型配置、任务及反馈归因、原双审/分歧/无效、quarantine/关闭和冷恢复。原生产verify/recover与SDK逐step还原绑定实际请求；不能假设每个request都有一个新header。CLI完成不等于内容全通过。检查结束后保存有限结果与准确范围，选择实际新缺口；不因没有研究而阻塞，也不凭此发布完整开发分支。

只有新profile和小工程文件；禁止复制运行时、依赖、日常数据或全历史。已自动审批拒绝的清理对象保持。保留首次错误与必要证据；本批不制造大缓存。
