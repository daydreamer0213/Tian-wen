# 自然复盘复用现成技能参考：有限适配设计

状态：按用户已确认的复用方向冻结实施；尚未授权任何新环境读取外部来源，也不是实际效果证据。

## 已继承的决定与确切缺口

用户要求正常使用即可自动复盘，并复用旧四阶段中已经存在的学习能力。自然任务、
反馈归因、研究选择、探索、独立评估及未来文字方法治理均保持；不要求用户提供
旧摘要材料包，不制造 Run/SkillUse，也不把文字方法冒充可执行技能晋升。

旧摘要链已通过原生目录读取、来源核验和真实适配；自然 GuidanceStudy 的提议者
尚不能发现或读取这些已准入来源。缺的是来源身份和提议材料连接，不是新技能平台。

当前原生 SkillRegistry 已有 snapshot/get；旧 inspectLearningSkills 已核验 provider、
modelInvocable、完整定义指纹和16KiB正文。旧 inspection 工具则要求真实旧分析子会话
及 RunBinding，不能拿普通研究冒充。自然 one-shot 当前只开放原生结果捕获工具。

## 方案比较与选择

1. **采用：模型选目录项，宿主精确只读，再交回新提议会话。** 复用原生目录和来源
   校验；不增加子会话工具权限。多一次提议会话，但可以明确记录选择、实际读取和
   后续使用声明。一项研究至多读取一个来源，和已有一次探索顺序组合即可。
2. 扩展原生 one-shot 的技能工具。可在同会话内读取，但当前没有现成的自然研究
   工具绑定，需要新增工具可见性及生命周期权限接线；不是这次最小适配。
3. 宿主提前读取全部来源。少一次提议，但没有模型选择就读取正文，且会扩大材料量，
   不采用。完全另建分析员或可执行技能治理也不属于本次目标。

正常故事：自然研究成立→看到精确准入的目录→可选择一个合适来源→核验实际定义→
模型选择不用、直接改编或先做一次已有探索→候选仍经过五案例十次正式评估。
反例：没有准入来源或模型认为不需要，沿用现有直接/探索/证据不足路径，不读正文。
失败故事：目录不完整、来源被替换、权限/支持撤回或进程中断，停止当前研究；不换
来源重试、不补跑、不把读取失败当成“已经学会”。

## 授权与环境边界

旧 LearningSkillAdmission 的九个来源身份字段及验证规则抽成可共享部分，旧11字段
严格解析和摘要范围含义不变。自然准入使用独立合同：共同身份、实际 scopeKey、
用途 `conversation-method-reference`，以及 `environmentDigest`。环境身份为
`sha256({kind:'tianwen.conversation-skill-environment.v1', evolutionRoot})`，其中
evolutionRoot 是宿主明确传入、实际用于初始化该 Runtime 的绝对路径原值。

实际 scopeKey 是 `conversation:${sha256({cwd: agent.session.header.cwd ?? null})}`，
其摘要本身含 `sha256:` 前缀；沿用来源任务的原值。它不含 DSH_HOME，因此不得把
同目录等同于同获准环境。宿主配置默认空列表，旧 learningSkillSources 不转成自然
准入；配置存在也须与当前研究作用域和实际持久化环境一致才允许目录读取。
当前 Evolution 服务没有公开 root/config getter；不穿透私有字段。Runtime 将同一
显式 evolutionRoot 传给自然研究服务。未显式配置该绝对路径时来源参考保持关闭，
其余自然研究继续正常工作。无需修改既有默认根目录算法，也不增加一个环境数据库。
这里绑定的是明确的学习持久化根目录，不声称已经识别 Windows 路径别名或任意 home。

来源准入属于本次运行的已加载配置；修改配置文件需要重载或重建运行实例，沿已有
释放流程取消旧调用。每个边界重查已加载的准入，不承诺文件未重载就即时撤销。

只有本环境明确准入的、自包含文本来源可见。来源来源地、固定版本、许可、审核时间、
原生 provider 和完整定义摘要保持可核验；不下载、执行外部代码，不开放工具或安装。
先前外部摘要来源许可只属于当时独立验收环境；不用于 Daily 或新环境。本次实现和
工程验证只用仓库内明示测试夹具，不调用该外部来源。

## 有界提议与隔离

只有初始提议可额外返回 `{inspectSource: "一个已提供的精确名称"}`。模型原有三个
选择保持；宿主严格拒绝混合选择。目录只含通过准入筛选及原生完整目录核对的元数据，
不提前 get 正文。无合格准入时不调用 snapshot/get，不增加模型调用，旧提议格式不变。

选择完成并取得真实持久化 proof 后，宿主重新查当前支持/同意/父方法/来源授权，
只读取选定名称，并验证完整定义与准入摘要、provider、可供模型引用及正文16KiB上限。
先保存不可替换的 source-reference-read 记录，再进入新 completed proposal Session。
重复收据不授权继续运行；启动沿用未完成研究停止，不重读。

后续提议拥有同一研究、同样的原始两来源、父方法及只读来源定义。最多还能选择一次
已有探索；读来源必须在探索之前，不提供任意回环。若先选探索，则后续不能再选择
来源；若先选来源再探索，探索观察后的最终提议仍获得同一冻结来源正文。每一步都
允许诚实地报告证据不足，不为通过验收而强制读取或探索。

来源文本只是非可信参考。案例设计、留出材料、任务执行者和独立评审都不接收该正文；
来源也不进入事实依据或引用白名单。当前用户请求和宿主边界优先。候选若借鉴方法，
只能体现为现有可评估文字规则；不保留源码材料中的个人事实或执行指令。

## 持久化证据与恢复

现有 GuidanceStudy 增加一份可选、不可替换的 source-reference-read 记录：studyId、
自然准入身份、实际完整定义及已完成初始选择的原生 proof。来源定义完整保存用于核验
同一指纹和后续请求中的实际材料，不只保存一个无法复核的摘要声明。定义须是可稳定
序列化的原生文本定义；整体材料仍服从既有大小限制，不截断或修改来源来凑通过。

该记录只能出现在已打开研究内、任何探索/候选/决定之前。同一研究、原生会话独立性、
现行权限/支持/父版本和当前质量规则沿用已有账本验证；当代质量校验只约束新增，
不破坏历史重放。精确重复幂等，改变内容拒绝。

读过来源的候选必须携带 `sourceUse`：该读取记录的指纹、`adapted`或`not-used`及
非空有限说明。没有读取记录就不能声称使用；没有声明不能把正文在提示词里出现称为
采用。候选原生 proof 必须绑定真实捕获的候选和这个声明，以及其请求中的同一来源。
模型声明只是可追踪的参考/改编证据，不是来源必然有用或候选已通过评估。

接受但未激活的恢复还须核验选择与最终提议的实际原生会话、精确捕获、请求材料和
冻结模型，以及当前自然来源准入。缺失、替换、失效均不激活且零新调用，不重新访问
来源注册表。不读过来源的旧研究保持原恢复路径；已合法采用的纯文字方法不依赖
未来持续读取来源，其撤回仍受现有支持/同意/退化规则管理。

## 验证与完成边界

工程增量只验证来源合同、目录与精确读取、账本顺序/历史重放、原生提议材料和声明、
与一次探索组合、非法/撤回/重启失败出口。复用旧学习技能检查和现有自然研究测试
设施；不新建总队列，不重跑R0–R10，不复活R11，不修任务专项答案。

代码稳定后统一做本分支整体验证/审查；新增连接的实模验证单列未证明约定及其决策
价值。没有实际发生的来源选择/探索不写成自然发生，更不编造未来收益。精确提交CI、
交付升级与未来效果仍是各自独立的未完成项。
