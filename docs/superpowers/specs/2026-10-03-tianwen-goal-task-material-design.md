# Goal Task 原始研究材料读取

基线 22da157。既有入账事件保存结果与摘要，不能取代原要求和执行材料。此包在首个 Task 请求前的原准备事件内保存小型原 Goal/Task/权限快照；SDK command、请求、工具和回答继续由原 SDK 日志保存，不复制运行环境或再建账本。

快照只含原 Goal id/objective/context/successCriteria/workspaceRoot/origin、原 Task 四字段和当时权限模式。使用原 Goal/Task 摘要规则并由 LongGoal owner 核对；旧准备无快照仍按原入账规则处理，不补造历史要求。只读读取接口返回原 command、准备/结果和截止原 turn/end 的完整 SDK 事件，明确缺快照；未保存的外部文件输入不能由当前项目文件替代。

现有结果入账消费同一个材料读取入口，异步读取后保留最后同步 Task/Goal/attempt、同意和关闭检查。研究读取允许之后正常改计划或放弃 Task，但只能返回原冻结快照，不将当前要求当旧要求。给定账本来源须逐字段吻合原准备/结果；缺失、损坏或错误来源明确失败。独立研究读取沿原 v3 同意，并在返回前复核，完整材料超过现有语义材料 512KiB 上限明确失败，不截断、不影响原结果入账。

这一包只交付材料恢复与真实消费者。没有独立语义结果、方法使用或研究资格授权；不生成反馈、重做任务或重评旧样本。下一沿已有原生双审和研究治理接线，独立记录功能、语义及方法版本。main/Daily NO-GO、原资格/停止/十工作日窗口保持。受控 SDK 检查只能作工程证据，D >=15GiB，复用依赖，无下载/容器。
