# 方法试验评审按证据项选引文：设计

E066 与 E067 的真实模型评审都把 `feedbackStandard.originalFeedback` 的原话填进 `evidenceQuotes`。它是下一题的评估标准，不在下一题的请求或答案证据中；宿主正确拒绝整份评审。E067 已证明“明确提示并展示合法示例”不能可靠避免此错误。目标是让新文本方法试验的结构化工具在提交前就不接受这种误引，同时保留合法判断、旧账本恢复与宿主严格校验。

对**新文本方法试验**在评审材料外层标记 `quoteProtocol: tianwen.evidence-item-quotes.v1`。`projectClaimEvidence` 继续把原请求、可用事实和新答案投影成有角色的证据项，不把反馈标准放入其中。评审的结构化 `evidenceQuotes` 保持原字段和 `string[]` 账本格式，但每一项只能从非空 `claimEvidence.items[].text` 的去重全集中选择。整项原文最长 384 个码点；答案逐条审计仍使用已有的精确短引文和来源 ID。因此总结引文选择整项不会取消逐条事实核对。宿主收到结果后再次检查选择值在这份全集中，恢复历史证明时按原生材料中有无协议标记选择对应规则。

若选项的 JSON 超过 98,304 UTF-8 字节，或没有可选证据项，本次研究失败关闭；不退回可随意填写的自由字符串。此次先限文本方法试验，文件任务与原结果审核维持当前协议，待文件材料预算单独设计。旧试验材料没有协议标记，仍接受原本的逐字子串并按旧原生请求恢复；不会重判 E066/E067。此变更只保证引文字段不能引用反馈标准，不保证模型判断准确、研究采用正确或未来任务有改善。

在测试中分别证明：新 schema 不包含反馈原话、拒绝它却接纳完整请求或答案项；宿主与恢复时都要求选项精确匹配；旧短引文仍能恢复；现有研究循环能用新选择完成模拟评审。工程通过后，另从准确包和全新隔离档前瞻验证真实模型行为，main/Daily 保持 NO-GO。
