### 小步 RED → GREEN

1. **B/C arms：** 当前 seed-only runner 停止；接入 exact 5 task input 后必须只调用一次
   `runControlledArms()`，得到 10 fresh execution Session 和 `awaiting-evaluator`。任一 stopped/
   terminal reject 立即生成 safe stopped receipt，后续 0 Agent。
2. **blind evaluators：** 只调用一次 `runControlledEvaluators()`；5 evaluator Session 无 cwd、只有
   submit tool。结果必须 `pass/all-gates-passed`；identity-exposed/inconclusive/rejected 停止。
3. **Shadow：** 使用 5 个与 evaluation 不同的 input/workspace/session，只调用一次
   `runControlledShadow()`；必须 pass 且仅 eligible-for-isolated-test-promotion。
4. **pointer：** 通过现有 Evolution facade initialize B@rev1；依次只调用一次 promote、rollback、
   restore；机器状态必须 C@rev2 → B@rev3 → C@rev4，三个 post-check Session distinct。
5. **receipt：** 汇总角色计数与实际 Session event request/tool/Evidence 计数，只输出 digest/finite
   label；不复制 raw material。
6. **stop：** 每一阶段插入 Provider/tool/persistence/identity/workspace/root/pointer fault，证明首个
   failure 后无下一 Agent/请求，且不 continuation partial activity。

### 必须固定的成功事实

- formal Sessions 恰 25：2/10/5/5/3；
- 25 个 Session 都来自实际 DSH Agent 并 durable；
- 实际 model request 数只记录，不与常量比较；
- B/C/Shadow/transition 每个 closed Run 都有 RunBinding v2、manifest/use、Outcome、acceptance
  Evidence 和 actual tool/time facts；
- evaluation=`pass`、Shadow=`pass`、three transitions=`verified`、final pointer=C@rev4；
- ordinary root Skill、legacy Champion、其他 controlled scope、real product root untouched；
- evidence labels 永久是 configured-provider-capable mechanism + development-only/synthetic-defect，
  测试运行本身仍标 scripted fixture，external Provider requests=0。
