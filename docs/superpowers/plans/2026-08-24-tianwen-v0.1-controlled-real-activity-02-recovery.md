## Task 5：唯一 activity-02 真实生命周期

所有外层命令只能使用 official `.CMD` 变量、PowerShell call operator 和 tokenized argv；stdout/stderr
分离，调用后立即保存 `$LASTEXITCODE`。禁止命令字符串和嵌套 shell。

严格顺序与次数：

1. `model use --model deepseek-v4-pro --data-dir <product-root> --json`：一次；
2. 合法 receipt 后 `model status --data-dir <product-root> --json`：一次，必须 V4 Pro/configured/0 request；
3. 前两步闭合后 `controlled-lifecycle --manifest <manifest> --data-dir <product-root> --json`：一次；
4. 保存唯一 lifecycle safe stdout/stderr/exit；
5. 无论前面成功或失败，
   `model use --model offline --data-dir <product-root> --json`：最多一次；
6. `model status --data-dir <product-root> --json`：最多一次，闭合 offline/0 request。

第一条 direct official invocation 即消费 activity-02。任一 nonzero、无合法 receipt、transport、Provider、
Candidate、evaluator、Shadow 或 transition failure 都立即停止后续正式阶段，只做 frozen offline 收尾；
不得改参数重试。真实 lifecycle 失败后可运行冻结 postmortem checker一次；passed 不补跑 checker。
