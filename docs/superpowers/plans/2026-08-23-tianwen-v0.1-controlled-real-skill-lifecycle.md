## 2. 全局不变量

1. DSH `0.1.0-rc.7` 是唯一 Agent Runtime；使用它的 Agent loop、Session、SkillRegistry scope、tools restriction/guard、cancel、Provider route 和 tool pipeline。
2. v1 evaluation、v1 negative-only Shadow/Promotion readiness、历史 `goal-live-smoke.v1` 和旧 ledger replay 原样保留。新的真实评测不调用旧 live-smoke budget path。
3. v2 没有 `maxModelRequests`、token、CNY、价格或 Tianwen 模型预算。`maxToolCalls` 是副作用授权上限，`maxElapsedMs` 是卡死安全停止。实际 model request count 只记录，不判门。
4. `maxRetries=0`、五任务、每个 B/C/Shadow task 一个正式 Session 和不得补跑，是评测真实性规则，不是模型预算。
5. 原始 prompt、模型 output、工具参数/结果、evaluator reasoning、路径、cwd、凭据不进入 Evolution；只存有限 label、ID、digest、score、counter、reason code。
6. development-only controlled defect 可以得到 mechanical pass，并进入 isolated test Shadow/Promotion；必须永久保留 `development-only`、`synthetic-defect` 和 `natural-user-evidence=not-claimed`。
7. 不使用 Artifact/global Champion；新 pointer 精确按 `scopeKey` 管理 governed Skill，只影响 transition 后新建的受控 Run。
8. 用户 2026-08-23 standing authorization 覆盖真实 Provider 评测、isolated Shadow、证据门控 Promotion、Rollback 和默认 restoration；不覆盖未冻结外部发布、凭据处理或不可逆作用。
