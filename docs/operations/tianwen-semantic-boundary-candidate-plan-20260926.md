# 事实来源边界候选：设计与验收计划

**目标：** 减少真实模型复核把无来源的确定性结论误归为“允许推断”，同时保留有来源的事实、明确可错的判断和正常建议。

现有[六题诊断](tianwen-semantic-review-six-case-results-20260926.md)是修改前的失败基线：036-S1 和 R6-W3 的已知错误被双评审 `met/met`。这两题来自用户真实任务答案，但本次重评属于固定答案诊断。语义漏判不能靠精确引用或 JSON 结构校验判定；扩大这些机械校验只会把格式问题与事实判断问题混在一起。

## 选择的最小改动

仅调整 `packages/tianwen-runtime-bundle/src/conversation-claim-review.ts` 中 v6 质量契约使用的复核指令。要求复核者按照**答案实际声称的语气**核对来源：无条件表述的状态、范围、必要条件和承诺是需要同范围证据的事实断言；不能因为它位于“风险”段，或复核者事后把它称作“推断”，就降级为 `inference/permitted`。可放行的推断必须在答案中保留可错性，并且来源确实支持它的前提与推断关系；独立建议、常识和用户请求的虚构仍按现有规则允许。

备选方式：直接用关键词拒绝“已就绪”“必须”“覆盖”等句式会误伤用户明确给出的同类事实；只把双评审分歧统一改判失败，无法处理两份一致的 036-S1、R6-W3 误放行；增加同模型第三评审会增加成本而不解决一致性偏差。因此先做一次有明确停止条件的提示指令候选，不改结构化审计、精确引用、分类、共识和发布门槛。
