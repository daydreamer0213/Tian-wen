未来来源保存规范化实际输入身份：文件读取顺序、路径大小写、输出路径顺序不能制造两项独立输入；原材料摘要仍精确绑定。旧缺字段来源按旧格式恢复，不补造身份，不作为新退化证据。旧普通回滚写入、历史重放和原关闭/支持撤回保持。
