## 只补改动后的连接

1. **文件交付**：正常请求依据有界文件材料产出文件。核对预先判定的交付类型、
   获准原生调用前的输入、真实最终产物、原任务与双评审绑定。只有看到实际问题，
   才给对应的自然纠正；不预填模型错误或评审结论。符合既有支持条件时，核对同类
   来源、原始输入副本、实际比较与结果落账。
2. **只读文件后聊天回答**：正常读取并回答，核对成功原生 read、冻结输入、空输出
   集合和无写入。符合既有支持条件时，核对只读副本比较。只验证捕获时，结论只能
   写“捕获通过”，不能写此类型完整学习已经通过。
3. **可选探索与参考**：优先利用前两类已形成的合格来源，不另建近似题库。先核对
   真实选择机会是否形成；只提供正常任务材料及既有合同允许的来源目录。允许直接
   提案、不探索、不读取、读取后不用、候选拒绝或无法定论。来源使用前核验批准的
   精确来源和环境范围；不把历史单次批准擅自扩大成新来源或新权限。
4. **收尾关闭与撤回**：在同一隔离环境普通关闭学习，核对历史保留和未来停止应用。
   若自然形成活动文件方法，再验证实际撤回；没有形成则记“真实活动方法撤回未观察”。
   预植活动记录和人工损坏只属于工程检查，不冒充真实采用或自然撤回。
